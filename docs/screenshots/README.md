# Screenshots

The demo is a screen recording (linked from the Devpost submission) rather than
stills. If you want stills in the main README too, drop them here and add the
image tags back to ../../README.md under "The same thing, in the actual apps".

Suggested filenames:

  telegram-add.png   — Telegram: /add showing the "Tracking ..." reply
  discord-list.png   — Discord: /list showing the Telegram-added deadline
  alert.png          — either channel: a ⏰ alert arriving unprompted

Take them on a phone or desktop, crop out anything personal, and keep them
under ~1MB each so the README stays quick to load.
